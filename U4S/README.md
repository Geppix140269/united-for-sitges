# U4S - Archivio di lavoro United for Sitges

Cartella di lavoro interna: documenti, immagini, prompt e report.
Non e' parte del sito pubblico.

## Struttura

| Cartella | Contenuto |
|---|---|
| `social/facebook/` | Testi della Pagina Facebook (descrizione, primo post) |
| `social/facebook/images/` | Immagine profilo (720x720) e copertina (1640x624) |
| `analytics/` | Stato e note su Vercel Web Analytics |
| `prompts/` | Prompt pronti da usare in altre sessioni (es. Claude in Chrome) |
| `reports/` | Report di avanzamento datati |
| `brand/` | Script e materiale per rigenerare le immagini dal logo esistente |

## Regole

- Nomi file in minuscolo, con trattini. I report iniziano con la data: `AAAA-MM-GG-titolo.md`.
- Gli asset di brand originali restano nella radice del sito (`favicon.svg`, `share-card.jpg`). Qui solo derivati.
- Niente password, token o dati personali in questa cartella.
